1. فكرة المشروع 
يهدف المشروع إلى بناء خط بيانات هجين يستقبل ملف بيانات الطلبات غير النظيف الذي سأقدمه لكم، ثم يختار طريقة التحميل المناسبة تلقائيًا  
حسب حجم الملف: تحميل دفعي باستخدام Python للملفات الصغيرة، أو معالجة متوازية باستخدامApache Spark للملفات الكبيرة. بعد ذلك
يطبق المشروع نمط ELT؛ حيث تُحمّل البيانات الخام أولًً إلى MongoDB دون حذف أو تنظيف مسبق، ثم تُحلل وتُنظف وتُصنف إلى بيانات
قابلة للاستخدام وبيانات يجب عزلها.
