RULE 01 — ARABIC_NUMERALS
الأرقام العربية
٠٠٠٥ أو ٣٢١
5000 أو 321
تحويل الأرقام العربية إلى لاتينية ثم إلى النوع الصحيح.
RULE 02 — CURRENCY_STANDARDIZE
رمز أو اسم العملة
5000 ريال يمني / ر.ي
YER
إزالة النص وتوحيد العملة إلى YER.
RULE 03 — THOUSANDS_SEPARATOR
فواصل الألف
125,000.00
125000.0
إزالة فواصل الألف والتحويل إلى رقم.
RULE 04 — WORD_PRICE
الأسعار بالكلمات
ألفان / خمسة آلاف
2000 / 5000
تحويل القيم المعروفة المحددة فقط.
RULE 05 — PHONE_NORMALIZE
رقم الهاتف اليمني
+967 77 123 4567
+967771234567
إزالة المسافات وتوحيد صيغة الرقم الدولي.
RULE 06 — EMAIL_REPEATED_SYMBOLS
البريد الإلكتروني
user@@mail..com
user@mail.com
إصلاح التكرار الواضح فقط، وإلا يُعزل السجل.
RULE 07 — DATE_STANDARDIZE
التاريخ القياسي
31-01-2025 / 2025/01/31
2025-01-31T00:00:00
تحويل التاريخ الصحيح إلى صيغة ISO 8601.
RULE 08 — TRIM_SYNONYMS
المسافات والمرادفات
مدفوع / مؤكد
تم الدفع / مؤكد
Trim وتوحيد القيم إلى القاموس القياسي.
